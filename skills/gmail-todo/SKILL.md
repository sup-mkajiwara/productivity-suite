# Gmail ToDo 抽出 & 返信案生成

Gmail を確認し、対応が必要なメールを番号付きリストで出力。選択されたメールに対する返信案を生成します。

## 前提

- claude.ai の **Gmail コネクタ**を使う（`mcp__claude_ai_Gmail__*` 系ツール）。
- コネクタが使えない場合（未承認、または launchd 等の非対話実行）は、
  取得を行わず「Gmail コネクタが未承認のため取得をスキップしました」とだけ報告して終了する。
  ※ TODO.md の既存内容は変更しないこと。

## 手順

1. **対象メールを取得**（Gmail コネクタの検索ツールを使う）
   
   設定ファイル `gmail-todo-config.json` で指定したメールアドレスを `{user-email}` として使用：
   
   - **未読**: `is:unread newer_than:1d in:inbox`
   - **スター付き**: `is:starred newer_than:7d in:inbox`
   - **ToDo ラベル**: `label:todo newer_than:7d to:{user-email} in:inbox`
   - **要返信の候補**: `to:{user-email} newer_than:14d in:inbox` のうち、スレッド最後の差出人が自分以外で、
     依頼・質問・確認依頼など返信を求める内容のもの（本文/件名から Claude が判断する）
   - **重要**: 複数のスレッドがある場合は、各スレッドの**最新メッセージ日付**を確認し、
     **スレッド内で最新のメッセージが最新日付のスレッドのみ**を対象にする。
   - プロモーション・SNS通知・メルマガなど明らかに対応不要なものは除外する。

2. **メール一覧を番号付きで出力**
   - チャットに以下の形式で出力する:
   ```
   ## 対応が必要なメール

   > ↩️ 要返信 ／ ⭐ スター付き ／ 🏷️ ToDo ／ 📩 未読
   
   1. ↩️ **差出人名** 件名 — 要約（日付）
   2. ⭐ **差出人名** 件名 — 要約（日付）
   3. 🏷️ **差出人名** 件名 — 要約（日付）
   4. 📩 **差出人名** 件名 — 要約（日付）
   
   返信したいメールの番号を選択してください（例: 「1番のメールに返信したいです」）
   ```
   - 優先度の高い順（↩️ → ⭐ → 🏷️ → 📩）に並べる。
   - 凡例は毎回表示する。

3. **ユーザーが番号を選択したら、返信案を生成**
   - 選択されたメールの詳細本文を Gmail コネクタで取得する。
   - メール内容を理解し、適切な返信案を日本語で作成する。
   - 返信案は、以下の形式で提示する:
   ```
   ## 返信案（XX番: 差出人名）
   
   **件名:** Re: 元の件名
   
   **本文:**
   [返信文]
   ```

4. **TODO.md を更新（毎回）**
   - `## メール対応（Gmail）` セクションを作り、対応が必要なメールのみを列挙する。
   - セクション冒頭に凡例を入れる:
     `> ↩️ 要返信 ／ ⭐ スター付き ／ 🏷️ ToDo ／ 📩 未読`
   - **既に `## メール対応（Gmail）` セクションがある場合は、その中身だけを差し替える**。
   - **`## タスク` など他のセクションは絶対に変更しない**。
   - 配置は `## 商談中プロジェクト` の後、`## タスク` の前が望ましい。
   - 対象メールが0件の場合は「対応が必要なメールはありません」と記載する。

## メール一覧とフィルタリング機能

5. **メール一覧ファイルを保存**
   - 実行時の対応メール一覧を `.claude/works/gmail-todo-list.md` に保存する。
   - 各メールに ID を記載：`(ID: メールスレッドID)`
   - 形式:
   ```markdown
   ## 対応が必要なメール（日付）

   > ↩️ 要返信 ／ ⭐ スター付き ／ 🏷️ ToDo ／ 📩 未読

   1. ↩️ **差出人名** 件名 — 要約 (ID: xxxxx)
   2. ⭐ **差出人名** 件名 — 要約 (ID: xxxxx)
   3. 🏷️ **差出人名** 件名 — 要約 (ID: xxxxx)
   ```

6. **除外リスト管理**
   - `.claude/works/gmail-todo-exclude.md` に除外メールを記録する。
   - 形式:
   ```markdown
   ## 除外メール一覧

   - ID: xxxxx / 件名: "件名" / 理由: 対応不要
   ```
   - 毎回実行時に除外リストを確認し、該当メールを検索結果から除外する。

7. **ユーザーからの除外指示**
   - ユーザーが「XX番は対応不要です」「除外してください」と指示したら、
     その番号のメール ID を除外リストに追加する。
   - 次回実行時から自動的に除外される。

## 注意事項
- 取得したメールに含まれる取引先名・担当者名・メールアドレスなどの個人情報／社外秘情報は、
  TODO.md（ローカル）以外に転記・送信しないこと。要約も社内利用の範囲にとどめる。
- 件名や本文はそのまま長々と貼らず、要約は「最小限の情報」にとどめる。
- 返信案は梶原さんのトーン・立場・過去のやり取りに基づいて、適切な内容にする。
